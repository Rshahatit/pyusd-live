Perfect — just like with top holders, we want accurate, live, and on-chain data for recent transactions. Let’s walk through how to get the 5 most recent PYUSD transactions, and make sure they’re legit (i.e., not just event noise or stale logs).

⸻

🎯 Goal: Show the 5 Most Recent PYUSD Transactions (Confirmed, On-Chain)

⸻

✅ Strategy Overview

Step	Tool	Purpose
1	BigQuery or GCP RPC	Get raw recent Transfer logs
2	Filter by PYUSD contract	Only show actual PYUSD events
3	Sort by block timestamp (desc)	Get most recent ones
4	(Optional) Enrich with tx data	From GCP RPC to show from, to, gas, etc.



⸻

🔁 Option A: Fastest + Easiest – Use BigQuery Logs

SELECT 
  transaction_hash,
  LOWER(SUBSTRING(topics[1], 27)) AS from_address,
  LOWER(SUBSTRING(topics[2], 27)) AS to_address,
  SAFE_CAST(CONCAT('0x', SUBSTR(data, 3)) AS BIGNUMERIC) / 1e6 AS amount,
  block_timestamp
FROM `bigquery-public-data.crypto_ethereum.logs`
WHERE address = '0x6c3ea9036406852006290770bedfcaba0e23a0e8' -- PYUSD
  AND topics[0] = '0xddf252ad1be2c89b69c2b068fc378daa952ba7f163c4a11628f55a4df523b3ef' -- Transfer
ORDER BY block_timestamp DESC
LIMIT 5

This gives you:
🧾 Tx hash, 👤 sender, 👤 recipient, 💸 amount, ⏱ timestamp

⸻

🧱 Option B: Real-time Using GCP Blockchain RPC

If you’re staying fully on-chain and don’t want to rely on BigQuery, you can:
	1.	Use eth_getLogs
	2.	Filter by:
	•	address = PYUSD contract
	•	topic[0] = Transfer event hash
	•	fromBlock = latest - 100
	•	toBlock = latest

const logs = await provider.send('eth_getLogs', [
  {
    address: '0x6c3ea9036406852006290770bedfcaba0e23a0e8', // PYUSD
    fromBlock: '0x...' // hex string block number
    toBlock: 'latest',
    topics: ['0xddf252ad...'] // Transfer
  }
]);

// Parse logs manually (you can use ethers.js log parser)

⚠️ Downside: May return too many results or rate-limit you on mainnet.

✅ Backend Route Example (BigQuery)

router.get('/recent-transactions', async (req, res) => {
  const [job] = await bigquery.createQueryJob({
    query: `
      SELECT 
        transaction_hash,
        LOWER(SUBSTRING(topics[1], 27)) AS from_address,
        LOWER(SUBSTRING(topics[2], 27)) AS to_address,
        SAFE_CAST(CONCAT('0x', SUBSTR(data, 3)) AS BIGNUMERIC) / 1e6 AS amount,
        block_timestamp
      FROM \`bigquery-public-data.crypto_ethereum.logs\`
      WHERE address = '0x6c3ea9036406852006290770bedfcaba0e23a0e8'
        AND topics[0] = '0xddf252ad1be2c89b69c2b068fc378daa952ba7f163c4a11628f55a4df523b3ef'
      ORDER BY block_timestamp DESC
      LIMIT 5
    `,
    location: 'US'
  });

  const [rows] = await job.getQueryResults();
  res.json({ recentTxs: rows });
});
